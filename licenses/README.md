# Licenses

- `GODOT_ENGINE_LICENSE.txt` and `GODOT_THIRDPARTY_NOTICES.txt` were written from the engine itself
  (`Engine.get_license_text()`, `Engine.get_copyright_info()`, `Engine.get_license_info()`) for Godot 4.7.2-stable.
  Ship both next to every exported build.
- Every other asset is listed in `../ASSET_MANIFEST.csv`. When a third-party asset is added, put its license file in
  this folder (named after the asset) and add a manifest row in the same commit.
- No generative AI art in the game. Concept boards shared for direction are references only and are not stored here.
