# Roadmap

Each gate ends with a runnable checkpoint, verification evidence and remaining risks.

- **Milestone 1** (this build): one champion, basic attack plus one ability, dummies, arena, tests, Windows export.
- **Gate 1, early network test**: two controllable instances in the arena with a server authority. Movement
  replication, server-validated attacks, damage, death, clean disconnect and reconnect, simulated latency. Record
  what still needs prediction, reconciliation and interpolation. Offline mode stays runnable. Localhost success is
  not internet readiness.
- **Gate 2, complete bot match**: small mirrored map, one lane, tower and core per team, small flanks, one neutral
  camp with a visible reward, minion waves, tower targeting, respawn, victory, results, restart. One champion,
  mirrored picks, bots fill slots.
- **Gate 3, three champions** (done in three passes: Oathwarden and Ashrunner, levels and one upgrade choice; second abilities; ultimates and passives. Batches B and C of docs/ROSTER.md added six more champions; every champion now also has a fourth ability on F): add the frontline fighter and the mobile skirmisher, complete kits gradually, one
  minimal progression system, a small set of upgrades, then one test of a choice between two ability upgrades.
- **Gate 4, playability and presentation**: readability, animation, audio, HUD, performance on a stated machine,
  bot reliability, match telemetry (duration, deaths, captures, damage sources, stalls).

Not until playtesting earns it: 5v5, more lanes, a large roster, matchmaking, accounts, store, engine change.
